# แจ้งเตือนประกาศผล (FR-15)

ติดตั้ง migration 20260924174000_notify_published_results.sql

เมื่อเปลี่ยนจากซ่อนเป็นเผยแพร่ผล ระบบแจ้งนักศึกษาที่มีผล approved/reserve/rejected ผ่านรายการแจ้งเตือนและคิวอีเมลเดิม บัญชีไม่ active ถูกข้ามตามกฎเดิม บันทึกซ้ำขณะเผยแพร่หรือซ่อนผลไม่แจ้งซ้ำ หากซ่อนแล้วเผยแพร่ใหม่ถือเป็นประกาศรอบใหม่และแจ้งอีกครั้ง

การบันทึกผลรายบุคคลยังมี final_decision ตามเดิม ขั้นนี้เพิ่มเหตุการณ์ประกาศผล ไม่เปลี่ยนนโยบายเวลาที่นักศึกษาเห็นผลรายบุคคล ไม่มีการแจ้งย้อนหลังให้ประกาศที่เผยแพร่ก่อนติดตั้ง migration

อีเมลต้องตั้งค่าผู้ส่งและ worker/cron เดิม คิวที่ส่งไม่สำเร็จยังอยู่ให้ worker ดำเนินการต่อ การส่งอีเมลล้มเหลวไม่ทำให้ประกาศผล rollback

ทดสอบด้วย supabase/tests/published_results_notifications.sql บนฐานข้อมูลทดสอบหลัง migrations และทดสอบเพิ่มเติมด้วยบัญชีนักศึกษา approved/reserve/rejected กับบัญชีที่ยังไม่มีผล ยืนยันว่าผู้ไม่มีผลไม่ได้รับแจ้ง และลิงก์เปิดหน้าประกาศผลถูกทุน
