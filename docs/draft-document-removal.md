# ลบเอกสารก่อนส่งใบสมัคร (FR-08)

ติดตั้ง migration 20260924172000_remove_draft_documents.sql ก่อนใช้ปุ่มลบ

ลบได้เฉพาะเจ้าของใบสมัคร draft ที่ยังไม่เคยส่ง ตรวจเวอร์ชันเอกสารและล็อกใบสมัครร่วมกับการส่ง/อัปโหลด เอกสารจะออกจากรายการปัจจุบันและไม่นับว่าครบตอนส่ง ข้อมูลไฟล์ทุกเวอร์ชันถูกย้ายไป private.removed_application_documents และไฟล์ใน Storage ยังเก็บไว้ ไม่มีการลบถาวรหรือหน้ากู้คืนในขั้นนี้

ตรวจในฐานข้อมูลทดสอบ:
1. นักศึกษา A บันทึกร่าง อัปโหลดเอกสารจำเป็น แล้วลบ: รายการหาย มี audit และ archive แต่ไฟล์ยังอยู่
2. ส่งใบสมัครโดยไม่อัปโหลดเอกสารจำเป็นใหม่: ต้องถูกปฏิเสธ
3. อัปโหลดใหม่แล้วส่ง: ทำได้เมื่อเงื่อนไขอื่นครบ
4. บัญชี B เรียก student_remove_draft_document ด้วย id ของ A: ต้องถูกปฏิเสธ
5. ส่ง version เก่าหลังแทนที่ไฟล์: ต้องได้ PT409 และไฟล์ใหม่ไม่หาย
6. เรียก RPC หลังส่ง หรืออยู่สถานะ revision_requested: ต้องถูกปฏิเสธ
7. ลบพร้อมส่งใบสมัคร: ต้องไม่มีใบสมัคร submitted ที่ขาดเอกสารจำเป็น
8. ลบ Storage ผ่านสิทธิ์นักศึกษาด้วย path ที่เก็บใน archive: ต้องถูกปฏิเสธ

การตรวจ lint/build ไม่แทนการทดสอบ RPC และ RLS ข้างต้น
