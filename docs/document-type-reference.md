# ประเภทเอกสารส่วนกลาง (FR-19)

ติดตั้ง migration 20260924173000_document_type_reference.sql ก่อนใช้งาน

Admin เพิ่ม แก้ชื่อ เปิด/ปิดประเภทเอกสารจาก /admin/reference ผ่าน RPC เดิมที่ตรวจสิทธิ์ เวอร์ชัน และเก็บ Audit Log เจ้าหน้าที่ใช้คำแนะนำชื่อเอกสารที่เปิดใช้งานในฟอร์มสร้าง/แก้ไขทุน ชื่อที่เลือกถูกบันทึกเป็นชื่อเอกสารของทุน ณ เวลานั้น ไม่เปลี่ยนย้อนหลังตามข้อมูลส่วนกลาง และยังระบุชื่อเฉพาะทุนได้

ตรวจบนฐานข้อมูลทดสอบ:
- Admin เพิ่มประเภทเอกสาร แล้วตรวจ Audit Log
- สร้าง/แก้ไขทุน: ชื่อปรากฏในรายการแนะนำและบันทึกได้
- ปิดประเภทเอกสาร: ไม่ปรากฏในคำแนะนำใหม่ แต่ทุนเดิมยังมีชื่อเดิม
- เปลี่ยนชื่อ: คำแนะนำใช้ชื่อใหม่ ทุนเดิมยังใช้ชื่อเดิม
- Student/Staff เรียก admin_save_reference: ต้องถูกปฏิเสธ
- Admin ส่ง version เก่า: ต้องถูกปฏิเสธ

ยังต้องทดสอบ RPC/RLS กับฐานข้อมูลจริงหรือฐานข้อมูลทดสอบหลังติดตั้ง migration; lint/build ตรวจเฉพาะโค้ดแอป
