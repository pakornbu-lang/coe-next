# ทดสอบลืมรหัสผ่าน

- ใช้อีเมลที่ลงทะเบียนในระบบทุน หรืออีเมลล่าสุดหากเคยเปลี่ยนอีเมล
- หน้าเว็บยืนยันว่ารับคำขอแล้ว ไม่ยืนยันการมีอยู่ของบัญชีหรือการส่งถึง Inbox
- หากผู้ให้บริการรายงานข้อผิดพลาด ต้องแสดงข้อผิดพลาด ไม่แสดงว่าสำเร็จ
- NEXT_PUBLIC_SITE_URL ต้องเป็น URL ของเว็บที่ผู้ใช้เปิดถึงได้ หากใช้ localhost ต้องเปิดอีเมลบนเครื่องที่รันเว็บ
- ช่องทาง Supabase ต้องอนุญาต URL /auth/callback?next=%2Freset-password ใน Redirect URLs และตั้งค่าการส่งอีเมลให้พร้อม
- ช่องทาง Apps Script ใช้ hashed_token จาก generateLink แล้วให้ /auth/callback ตรวจด้วย verifyOtp ชนิด recovery และบันทึก session ใน cookie ก่อนเปิด /reset-password
- ลิงก์เก่าที่ส่งก่อนแก้โค้ดอาจยังใช้ไม่ได้ ให้ขอลิงก์ใหม่
- ทดสอบแบบจำลองโดยไม่ส่งเมลหรือเปลี่ยนรหัสจริง: node scripts/check-password-reset-flow.mjs
- ทดสอบจริง: ส่งคำขอหนึ่งครั้ง เปิดลิงก์ล่าสุด ตั้งรหัสใหม่ด้วยตนเอง แล้วเข้าสู่ระบบใหม่ ตรวจลิงก์ที่ใช้แล้วว่ามีคำเตือนและขอลิงก์ใหม่ได้
